# Changelog

## 0.3.0 — rebuilt

- Kept manual invocation with `disable-model-invocation: true`.
- Returned the core to a lightweight attention posture rather than an explicit decision workflow.
- Preserved three optional ways to gain information: ask the user, inspect reality, or open a fresh independent context.
- Removed the `direct / ask / probe / scout` routing taxonomy from the skill.
- Removed formal scoring, pass thresholds, synthetic evaluation suites, validation scripts, and release gates.
- Reduced fresh-context guidance to an optional reference instead of a mandatory protocol.
- Kept inferred purposes and human motives provisional.
- Made direct action a first-class success when another frame would not change the work.

## 0.2.0

- Replaced a rule-heavy first version with a concise attention-oriented core.
- Centered purpose, perspective, evidence, and return to concrete action.
