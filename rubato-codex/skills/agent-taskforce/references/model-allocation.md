# Model allocation

Read the bundled [model-guide](../../model-guide/SKILL.md) before choosing a
model. It owns seat allocation, Fable/Astra approval, provider selection from
`$CODEX_HOME/rubato-codex/providers.json`, native-only defaults and exact-ID
resolution. Do not maintain a second model table here.

Role files deliberately omit model and effort. The user chooses the lead;
native execution and the actual spawn schema remain authoritative. Selected
providers do not imply that their models are callable in the current session.
