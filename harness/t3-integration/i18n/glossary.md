# Korean UI glossary

The user decided these terms and the tone. Change them only on the user's word.

## Tone
- Default: 합니다체 for statements, descriptions and status ("저장됩니다", "찾을 수 없습니다").
- Never 하십시오체. When asking the user to do something, use 해요체 polite request ("확인하세요", "다시 실행하세요").
- Mix in 해요체 where a sentence talks to the user directly and 합니다체 would feel stiff (questions: "연결을 해제할까요?").
- Buttons and action menu items: verb + 하기 ("저장하기", "다시 시도하기", "스레드 고정하기"). Section titles, tab names and field labels stay nouns ("고급", "런타임", "글꼴 크기").
- Errors: present tense ("열 수 없습니다", not "열 수 없었습니다").

## Keep in English
PR (pull request), branch, worktree, merge, push, fetch, rebase, clone, checkout, repo (repository), diff, stash, fork, rewind.
Model options: Reasoning, Fast, and the effort levels Low, Medium, High, Extra High, Max.
Product names: T3 Code, T3 Connect, Rubato, GitHub, ChatGPT, Codex, Cursor, WSL, Tailscale, macOS, Mac.
