# 행동 체크리스트 — 이 스킬을 실행한 세션의 실패 모드

실전 사용 후 이 목록으로 세션 행동을 리뷰한다. 하나라도 걸리면 SKILL.md의 해당 판단 조건과 이유를 다시 본다. 규칙을 덧붙이기 전에 기존 문단을 고친다.

## 함께 생각하기

- [ ] 원안 원문(raw-brief)과 사용자 원안(HUMAN_SEED)을 보존하지 않고 AI 후보로 덮었는가
- [ ] AI 후보가 표현만 다른 변형이었는가
- [ ] 최종 문서에 제안 출처(HUMAN_SEED / AI_PROPOSED / USER_ADOPTED·MODIFIED·REJECTED)가 빠졌는가
- [ ] 모르는 칸을 추측으로 채워 작성된 것처럼 처리했거나, 제안 출처와 증거 등급을 섞었는가 (모델이 썼다고 E0로 깎거나, 사용자가 채택했다고 등급을 올림)
- [ ] 아직 탐색 중인 대화를 1→8 필드 설문으로 바꿨는가
- [ ] 새 근거 없이 같은 반론을 반복했거나, 대화를 끝내려고 승인·보호 조건을 면제했는가
- [ ] 사용자가 유지한 결정과 남은 이견을 구별해 기록하지 않았는가
- [ ] 사실·가치판단·최종 선택을 사용자 확정 없이 모델이 정했는가

## 점검표 판정

- [ ] 결격 사유가 있는데 "전반적으로 좋다"며 통과시켰는가 (점수 평균 금지 위반)
- [ ] 판정에 원문 인용 없이 "채워짐"으로 처리한 필드가 있는가
- [ ] PASS/FAIL 기준을 실험 후에 정했거나 결과를 보고 바꿨는가
- [ ] 탐색 실험(discovery)을 마친 것을 제품 성공으로 보고했거나, 탐색이라는 이름으로 무대·실전 보호 조건을 뺐는가
- [ ] 연습급 실험에 8필드 전체를 요구했는가 (점검표 비용 > 실패 비용)
- [ ] 반대로 결제·개인정보가 걸린 건을 연습으로 통과시켰는가

## 동결과 구현

- [ ] 사용자 승인 전에 FRAME_LOCK을 발행했는가
- [ ] 동결 없이 아웃컴·완료 조건·사용자 경험에 종속되는 구현 계획·위임을 시작했는가 (되돌리기 쉬운 스캐폴딩은 동결 전에도 허용)
- [ ] 구현 중 불변식 6개(사용자·트리거·현재 대안·약속한 아웃컴·비교 가치·도입 경로·생태계 연결 사슬) 중 하나라도 버전 증가 없이 조용히 바꿨는가
- [ ] 워커 브리프에 프레임 문서 경로를 빼먹었는가
- [ ] "구현이 귀찮다"류 사유로 동결 해제를 승인했는가

## 상태 전이와 운용 단계

- [ ] 실전 부록(§9)이 미완인데 구현 승인(PASS-BUILD)을 발행했는가
- [ ] 동결 해제 결정 기록(APPROVED/REJECTED + approved_by·approved_at) 없이 종결 전이를 수행했는가
- [ ] 이전 프레임을 동결 해제 승인 시점이 아닌 다른 시점에 SUPERSEDED로 바꿨는가
- [ ] 저장소에 ACTIVE 동결이 두 개 존재하는가 (SUPERSEDED 처리 누락)
- [ ] EXPIRES_AT이 지난 동결로 새 위임을 했는가
- [ ] 결격 사유를 예외 승인으로 같은 점검표에서 통과시켰는가
- [ ] 연습에서 결격 사유 검사(사람과 장면·현재 대안, 바라는 변화, 실험 종류별 사전 내용, 범위·중단 조건·승인)를 건너뛰거나 일부만 적용했는가
- [ ] 통상적인 해커톤 데모를 브랜드 노출 사유로 실전으로 올렸는가
- [ ] 가장 위험한 가정 교체를 동결 해제로 처리했는가 (실험 회차 증가로 처리해야)
- [ ] 무대인데 도입 경로나 문제 압력·전환 비용 없이 통과시켰는가

## 위임

- [ ] 무대 이상에서 레드팀·블라인드 리뷰를 초안 작성에 참여한 세션이 했거나, 같은 세션의 역할 전환을 독립 검토로 보고했는가
- [ ] 사용자와 주고받아야 할 대화를 서브에이전트로 보내 왕복 낭비를 만들었는가
- [ ] 후보가 전부 비슷하거나 탐색이 수렴하지 않는데 `product-reframing` 제안 없이 그대로 밀어붙였는가
