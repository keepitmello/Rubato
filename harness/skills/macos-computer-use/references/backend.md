# Backend

Default: Peekaboo 4.2.0, local only.

Do not use the Peekaboo remote Bridge on this machine unless a later bench shows it is healthy. The first Finder/ComputerUseBench `see` calls failed with incomplete exact-window identity until `--no-remote` was set.

Cua 0.20.0 remains installed at `/Applications/CuaDriver.app`. Use it only if Peekaboo cannot target the surface and Cua's AX token path is explicitly needed.

Codex built-in Computer Use is the Desktop `node_repl` path. It is not scriptable from a normal Node process.
