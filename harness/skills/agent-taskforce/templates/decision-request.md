# Decision request

decision_class: TEAM_CONTRACT | RESOURCE | HIGH_BLAST_RADIUS | COMPLETION

**Decision needed:** the one sentence the lead must decide.

**Verified facts:** only facts confirmed by tests, inspection, artifacts, or source.

**Options:** the genuinely available choices and their significant tradeoffs.

**Recommendation:** the preferred option and why.

**Impact:** affected workstreams, interfaces, files, scope, done evidence.

**Remaining uncertainty:** what is still unknown, and whether it blocks.

> If an active FRAME_LOCK invariant is involved, use `frame-conflict.md` instead of this form.
