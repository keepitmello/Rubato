# Fresh context as an opening

A fresh context is useful when the current conversation may be shaping what looks obvious. Its purpose is not to create a committee, produce more text, or hand the decision to another agent. It gives the problem one independent chance to be represented differently before the main agent commits.

## When it may help

Consider it when the current explanation has become unusually obvious or elegant, a proposed solution may be hiding the operating result, several local fixes have failed, or the level at which the problem is defined could change the action.

It usually adds little when the task is exact, inexpensive, reversible, or answerable through a direct read, test, or search.

## Preserve independence

Give the fresh context:

- the user's original request or assignment;
- explicit boundaries and constraints;
- confirmed facts and authoritative evidence;
- genuinely unresolved unknowns.

Leave out the current conclusion, preferred remedy, production transcript, and summaries written around the current theory. A summary can carry the same anchor as the full conversation.

A compact request is enough:

> Look at this task before adopting a solution. Is there a materially different way to represent the problem that would change what should be done? What user answer or external evidence would distinguish it? It is valid to conclude that the current framing is already adequate.

## Bring the result back lightly

Treat the response as a source of hypotheses and discriminating questions. Compare it with the user's stated intent and the available evidence. Novelty, abstraction, confidence, and agreement among similar agents do not make a frame true.

Use the new perspective only when it improves a real choice, test, boundary, or action. Then return to the original work.

## Host note

For genuine independence, use a new session or an ordinary isolated subagent rather than a fork that inherits the current conversation. If the host cannot provide isolation, prefer a focused user question or an external probe over pretending the review is fresh.
