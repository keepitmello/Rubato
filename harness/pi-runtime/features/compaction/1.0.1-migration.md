# 0.86.1 → 1.0.1 패치 재판정

대조 원본은 pristine 0.86.1 설치본이고, `preimageSha256`과 `version`(`PI_VERSION`)은
중앙에서 다시 기록됐다. delete 0.

| 패치 | 판정 | 사유 |
|---|---|---|
| `dist/api/anthropic-messages.js` (pi-ai) | re-cut | `anthropic-import`가 죽었다: SDK import가 `import Anthropic, {} from "@anthropic-ai/sdk";`로 바뀌었다. 바로 뒤 `claude-code-version`도 죽을 자리였다: stock 리터럴이 `2.1.251`에서 `2.1.280`으로 올랐다. 이제 stock이 어떤 리터럴을 싣든 한 번 매칭해서 `misc-claude-code-version.mjs`의 상수로 굽는다 — 값이 지금은 같아도 정본은 그 상수 하나로 남는다. 나머지(billing header, params seam, compaction 블록/델타/usage, cut·omit·replay)는 그대로 붙는다. |
| `dist/core/compaction/compaction.js` | keep | 1.0.1은 압축 준비를 세션 projection(`buildSessionProjection`) 기반으로 바꾸고 turn-prefix 프롬프트 문구를 고쳤다. 우리 앵커(요약 프롬프트 템플릿, `shouldCompact` 비율, Cursor thinking 제거, tool-call fallback 두 곳)는 그대로 붙고, fallback이 쓰는 `conversationText`/`completionOptions`/`createSummarizationOptions(...)`/`buildSummarizationContext`/`retry`/`callbacks`는 같은 스코프에 그대로 있다. `generateSummaryWithUsage`는 0.86.1과 바이트 동일하다. |
| `dist/core/settings-manager.js` | keep | `getCompactionSettings(model)` 앵커 그대로. |

## 확인한 의미 변화

- 자동 압축 판단: 1.0.1 `_exceedsCompactionThreshold(model, projection)`는 `model.contextWindow`와
  `getCompactionSettings(this.model)`을 쓴다. 비가상 모델이면 `model === this.model`이라 0.86.1과 같다.
  가상 모델(1.0 신규)을 고르면 창 크기는 라우팅된 모델, 우리 비율(`settings.model`)은 선택한 가상
  모델 기준이 된다. Rubato는 가상 모델을 등록하지 않으므로 지금 동작은 같다(위험 항목).
- Anthropic inline 도구 정의(1.0.1)는 compaction replay 경로를 건드리지 않는다.
