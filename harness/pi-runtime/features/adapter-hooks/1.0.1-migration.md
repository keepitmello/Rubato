# 1.0.1 judgments

No engine patch moved. One semantic change taken on: 0.99 sends a returned `{ isError: true }` as an
error tool result. A failing PTY bash or eval cell was a plain result on 0.86, so its large output was
previewed. `tool-output-policy.mjs` now keeps previewing `bash`/`powershell`/`eval` output when it is
an error; other failures stay exempt.
Tests: `tool-output.test.mjs` "a large failing shell or eval output is still previewed".
