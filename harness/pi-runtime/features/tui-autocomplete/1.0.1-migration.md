# 0.86.1 → 1.0.1 패치 재판정

intent `pi-1-0-upgrade` revision 1. 대조 원본: 0.86.1·1.0.1 npm 설치본(pristine).

| 패치 | 판정 | 사유 |
|---|---|---|
| `autocomplete.js` autocomplete-leading-slash | re-cut | 1.0.0(#10218)이 `const commandText = textBeforeCursor.trimStart()`로 판정해 앞 공백 뒤 `/`에도 명령 메뉴를 연다. 이 패치는 이름과 달리 공백 처리가 아니다. 하는 일은 셋이다: `$` 호출 완성, 명령 메뉴의 첫 줄 제한(에디터가 인라인 `/skill:` 때문에 모든 줄에서 슬래시 메뉴를 연다), `/a/b`는 경로라 명령 완성을 안 하는 규칙. 셋 다 업스트림에 없어 지울 수 없다. `commandText` 위에 다시 걸었다. |
| `autocomplete.js` autocomplete-import / inline-skill / apply | keep | 앵커가 그대로다. 1.0의 경로 래퍼(`(`, `` ` `` 등) 처리는 우리가 바꾸는 구간 밖이다. |
| `components/editor.js` (3 앵커) | keep | 앵커가 그대로다. `isSlashMenuAllowed`·`isAtStartOfMessage`·`isInSlashCommandContext` 사용처 10곳도 0.86.1과 같다. 1.0의 트리거 정규식 래퍼 변경은 우리 구간과 겹치지 않는다. |

## 동작이 바뀌는 한 곳 (판단)

첫 줄에 앞 공백 + `/res`를 치는 경우:

| | 결과 |
|---|---|
| 0.86.1 + Rubato | 스킬만 나온다. stock 판정이 실패하고, 우리 인라인 `/skill:` 경로가 대신 받았다. |
| 1.0.1 + Rubato (re-cut) | 모든 명령이 나온다. 업스트림 #10218 수정이다. |

옛 결과는 의도한 기능이 아니라 부산물이라 업스트림 수정을 받았다. 정확히 옛 동작으로 되돌리려면
`trimStart()`를 빼야 하는데, 그건 업스트림 버그 수정을 되돌리는 일이다. 테스트가 새 동작을 잡는다.

  `get-east-asian-width`는 `findPackageJSON`으로 찾는다.
