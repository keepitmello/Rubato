# 0.86.1 → 1.0.1 패치 재판정

intent `pi-1-0-upgrade` revision 1. 대조 원본: 0.86.1·1.0.1 npm 설치본(pristine).

| 패치 | 판정 | 사유 |
|---|---|---|
| `interactive-mode.js` header-logo | re-cut | 0.99는 헤더 첫 두 줄을 pi 하프블록 로고 + 엔진 버전으로 바꿨고, 1.0.0은 Apple Terminal에서 색깔 "Pi" + 버전을 쓴다. 로고 클릭은 3D 로고를 재생한다. 우리 헤더는 지금처럼 `BRAND_NAME`(굵은 accent) + dim ` v<제품 버전>` 한 줄이고 안내는 그 아래 줄에 온다. 그래서 `showLogo = supportsPiLogo()`와 `withLogo`를 우리 한 줄로 바꾸고 `showLogo = false`로 둔다. 로고를 안 그리니 클릭 핸들러도 안 붙는다. 헤더 텍스트를 매 렌더마다 만드는 1.0 방식(테마 변경 추종)은 유지한다. |
| `interactive-mode.js` header-import | keep | config import 줄이 그대로다. |
| `interactive-mode.js` hide-extensions | keep | `addLoadedSection("Extensions", …)` 줄이 그대로다. 1.0은 목록 인자를 지연 함수로 바꿨을 뿐이고, 그 줄을 주석으로 바꾸는 의미는 같다. |

## 테스트

- 새 테스트 "1.0 header renders the brand line…": 패치된 소스에서 헤더 빌더를 꺼내 실제 dark 테마로
  렌더한다. 결과가 `bold(accent(BRAND_NAME)) + dim(" v"+버전) + "\n" + 안내`와 같고,
  `showLogo === false`이고, pi 로고 함수가 호출되지 않는지 본다.
