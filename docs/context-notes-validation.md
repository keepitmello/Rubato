# 두 번째 버전에서 실행한 검증

검증일은 2026-09-06이에요. 전달 파일을 대상으로 Node 22.16.0에서 검사했어요. 실제 서비스·모델·사용자의 로컬 세션은 호출하거나 읽지 않았어요.

## 실행한 명령

```sh
cd harness/rubato-pi
node --test test/unit/context-notes-*.test.mjs test/unit/context-cost-*.test.mjs
RUBATO_CONTEXT_MODE=summary node --test test/unit/context-notes-*.test.mjs test/unit/context-cost-*.test.mjs
```

전달할 모든 `.mjs` 파일에는 `node --check`를 실행했어요. 원문 합산 명령과 시뮬레이션 명령도 별도의 합성 파일로 실제 실행했어요. 계산된 사용량을 독립 산술식으로 대조했고 출력에 대화 본문이 들어가지 않는지 확인했어요.

새 회귀 검사는 고정 안내가 다음 요청의 앞부분에 그대로 남는지, 재시작·되돌리기·새 창에서 위치가 올바른지, 노트 뒤 늦게 도착한 작업 결과를 버리지 않는지, 비동기 처리 뒤 실제 저장 직전 검사까지 도달하는지 확인해요. 변환한 시험용 코드를 실제로 실행하는 검사도 포함해요.

저장 후 후처리 실패 시 다음 요청을 막고 중복 전환하지 않는지, 같은 노트 도구 호출 식별자가 다른 인수로 재사용되면 거부하는지, 검색·목록 이어보기와 파일 권한이 올바른지도 검사해요.

비용 검사는 캐시 입력을 일반 입력과 중복 계산하지 않는지, 1시간 쓰기를 전체 쓰기에 다시 더하지 않는지, 추론 토큰을 출력에 중복 계산하지 않는지, 서버 압축 투영을 다시 과금하지 않는지 확인해요. 아스트라 정확히 272K 경계에 할증이 붙지 않는지와 불가능한 후보에 허위 금액을 내지 않는지도 검사해요.

## 아직 실행하지 않은 검사

실제 Node 24 고정 엔진에서 필수 변환 여섯 곳이 적용되는지는 로컬에서 확인해야 해요. 실제 SessionManager 통합 검사, 실제 AgentSession 전체 도구 반복, 공급자에게 보내는 최종 요청, 실제 모델의 노트·원문 복구, 원격·터미널 화면은 아직 검사하지 않았어요.

전체 저장소 빌드·형 검사·기존 전체 테스트가 성공했다고 주장하지 않아요. 이 환경의 공개 저장소 다운로드는 DNS 오류로 실패했고, GitHub 연결에서 본 소스와 로컬 배포 패키지가 같다고 단정하지 않아요.

설치본 검사 도구가 현재 환경에서 중단한 메시지는 다음과 같아요.

```text
로컬 검증에는 저장소가 요구하는 Node 24 이상이 필요해요.
```

화면 검증 상태는 `IMPLEMENTED, RENDER VERIFICATION PENDING`이에요. 실제 루바토 화면에서 전환·오류·다시 열기 경로를 확인한 뒤 갱신해요.
